# Claude Code Settings

全プロジェクト共通の Claude Code 向けグローバル指示。
`~/.claude/CLAUDE.md` から symlink する想定。

## 言語

- 常に日本語で応答すること (Always respond in Japanese)

## ツール利用ルール

- `AskUserQuestion` ツールは使わない。インタラクティブな選択肢 UI を表示するとターミナルの表示が崩れる。
- ユーザーに選択を求める場合は、通常のテキスト出力で番号付き一覧として選択肢と各オプションの説明を提示し、ユーザーの返答を待つこと。プランモードでの選択肢提示も同様。

## ファイル変更の方針

- Claude Code が変更を加えるファイルは、基本的に git などでバージョン管理されているものに限定する。誤って修正・削除した場合でも復元できる状態を保つため。
- git 管理外のファイル（untracked / `.gitignore` 対象 / リポジトリ外）を修正・作成・削除する必要がある場合は、対象パスと意図を明示したうえで必ずユーザーに確認を取ること。確認なしに手を入れない。
- 確認すべきかの判断は、編集前に `git ls-files --error-unmatch <path>` や `git check-ignore <path>` 等で必要に応じて確かめる。リポジトリ外の絶対パス（`~/Library/...` など）は常に確認対象。
- スクラッチパッド（環境から提示される一時ディレクトリ）への書き込みは、作業用の一時ファイルに限り確認不要とする。
